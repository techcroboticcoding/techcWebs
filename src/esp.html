MATERI 1

Pengenalan ESP32

Mengenal ESP32, fungsi, kemampuan, dan penggunaannya dalam berbagai proyek elektronik.

1. Apa itu ESP32?

ESP32 adalah sebuah mikrokontroler yang dapat digunakan untuk mengendalikan berbagai perangkat elektronik seperti LED, tombol, sensor, buzzer, motor, dan perangkat lainnya.

ESP32 banyak digunakan dalam proyek robotik, otomasi, elektronik, dan Internet of Things (IoT).

Intinya:

ESP32 dapat menerima data dari sensor, memproses data tersebut, kemudian memberikan perintah kepada perangkat lain.

2. Apa itu Mikrokontroler?

Sebelum mempelajari ESP32, kita perlu memahami istilah mikrokontroler.

Mikrokontroler adalah sebuah perangkat elektronik yang dapat diprogram untuk menjalankan suatu tugas tertentu.

Contohnya, kita dapat memberikan program kepada ESP32 untuk:

  • Menyalakan dan mematikan LED.
  • Membaca tombol.
  • Membaca sensor.
  • Mengontrol servo.
  • Mengontrol motor.
  • Mengirim data melalui WiFi.

3. ESP32 Digunakan Untuk Apa?

ESP32 dapat digunakan untuk berbagai macam proyek.

🤖

Robotik

Mengontrol motor, sensor, servo, dan berbagai komponen robot.

🌐

IoT

Menghubungkan perangkat dengan jaringan dan mengirim data melalui internet.

💡

Otomasi

Mengendalikan perangkat secara otomatis berdasarkan kondisi tertentu.

📡

Komunikasi

Digunakan untuk komunikasi dengan perangkat lain melalui berbagai antarmuka.

4. Mengapa Menggunakan ESP32?

Salah satu alasan ESP32 banyak digunakan adalah karena memiliki kemampuan yang sangat lengkap untuk berbagai proyek mikrokontroler dan IoT.

✓
Banyak GPIO

Dapat digunakan untuk menghubungkan berbagai sensor dan perangkat.

✓
WiFi

Memungkinkan ESP32 terhubung ke jaringan internet.

✓
Bluetooth

Beberapa varian ESP32 mendukung komunikasi Bluetooth nirkabel.

✓
Dapat Diprogram

ESP32 dapat diprogram menjalankan berbagai instruksi sesuai kebutuhan proyek.

5. ESP32 dan Arduino

ESP32 dan Arduino sama-sama dapat digunakan sebagai pengendali pada proyek elektronik. Namun keduanya memiliki spesifikasi dan karakteristik yang berbeda.

Arduino Uno ESP32
Cocok untuk mempelajari dasar mikrokontroler. Cocok untuk mikrokontroler, komunikasi, dan IoT.
Tidak memiliki WiFi bawaan. Memiliki WiFi bawaan.
Umumnya untuk proyek elektronik dasar. Dapat digunakan untuk proyek yang membutuhkan konektivitas jaringan.

6. Istilah yang Perlu Dipahami

GPIO

Pin yang dapat digunakan sebagai input atau output.

Input

Data yang dibaca oleh ESP32, misalnya dari tombol atau sensor.

Output

Program

Instruksi baris kode yang dieksekusi oleh ESP32.

MATERI 2

Mengenal Board ESP32

Mengenal bagian-bagian board ESP32, fungsi pin, tombol, port, dan cara memberikan sumber daya.

1. Apa itu Board ESP32?

Board ESP32 merupakan papan pengembangan (development board) yang menggunakan chip ESP32 sebagai mikrokontroler utamanya. Board ini menyediakan header pin dan konektor siap pakai.

Intinya:

Chip ESP32 adalah otaknya, sedangkan board ESP32 menyediakan kaki pin dan sirkuit pendukung agar mudah dihubungkan ke rangkaian elektronik.

2. Mengenal Bagian-Bagian Board ESP32

Bagian-bagian penting pada board ESP32 antara lain:

  • Chip ESP32: Mikrokontroler utama pemroses program.
  • Pin GPIO: Pin input dan output periferal.
  • Pin 3.3V & VIN: Pin penyedia daya dan input voltase.
  • Pin GND: Ground (titik 0V sirkuit).
  • Port Micro USB / Type-C: Untuk upload kode dan sumber daya.
  • Tombol EN / RST: Tombol restart/reset mikro.
  • Tombol BOOT: Digunakan untuk mode flash/uploading program.

3. Pin GPIO

GPIO (General Purpose Input/Output) dapat diprogram secara fleksibel:

Sebagai Input: Membaca status push button, sensor cahaya, dsb.

Sebagai Output: Mengaktifkan modul relay, buzzer, atau LED.

4. Sumber Daya (3.3V, VIN, GND)

ESP32 beroperasi pada level logika 3.3V. Jangan memberikan tegangan 5V secara langsung ke pin GPIO karena dapat merusak mikrokontroler.
